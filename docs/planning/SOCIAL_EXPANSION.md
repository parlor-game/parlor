# Parlor social expansion

The baseline is protected main at `d9f78320ffdfa3f4b22342f975166b214dca9671`.
The app ships a host-authoritative same-LAN session model, game bindings at
the Compose composition root, and protected recovery storage. The Shared UI
reference is the Obsidian Amber v3 browser demo. Its local profile records
illustrative results. Production statistics require durable authoritative
completion events.
